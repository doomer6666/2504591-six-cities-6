# Как работать над проектом

## Окружение

Для удобства работы над проектом используются инструменты из **Node.js** и **npm**.
Все необходимые настройки произведены. Убедитесь, что на рабочем компьютере
установлен актуальный LTS-релиз Node.js. Актуальная версия Node.js указана в файле
`package.json` в поле `engines`. Затем, в терминале, перейдите в директорию с
проектом и _единожды_ запустите команду:

```bash
npm install
```

Команда запустит процесс установки зависимостей проекта из **npm**.

## Запуск проекта

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Создайте файл `.env` в корне проекта на основе `.env.example` и заполните его
   значениями (см. раздел «Переменные окружения»):

   ```bash
   cp .env.example .env
   ```

3. Запустите базу данных MongoDB. Если используете Docker, в корне проекта есть
   `docker-compose.yml`:

   ```bash
   docker compose up -d
   ```

4. (Необязательно) Наполните базу тестовыми данными. Сгенерируйте TSV-файл и
   импортируйте его (требуется запущенный `json-server`):

   ```bash
   npm run json-server
   npm run cli -- --generate 10 ./mocks/test-data.tsv http://localhost:3000/api
   npm run cli -- --import ./mocks/test-data.tsv <db_user> <db_password> <db_host> <db_name>
   ```

5. Запустите сервис:
   - в режиме разработки:

     ```bash
     npm run start:dev
     ```

   - в production-режиме (сборка + запуск):

     ```bash
     npm start
     ```

При старте сервис проверяет наличие всех обязательных переменных окружения. Если
какая-либо переменная не задана — сервис выводит сообщение об ошибке и завершает
работу.

## Переменные окружения

Список всех переменных окружения, необходимых для работы сервиса. Значения по
умолчанию приведены в файле `.env.example`.

Формат: `PARAM=value — описание`

- `PORT=4000` — порт, на котором запускается REST-сервис.
- `HOST=localhost` — хост, на котором запущен сервис (используется для построения
  ссылок на статические ресурсы).
- `SALT=super-secret-salt` — соль для хеширования паролей пользователей.
- `DB_HOST=127.0.0.1` — IP-адрес сервера базы данных MongoDB.
- `DB_USER=admin` — имя пользователя для подключения к базе данных.
- `DB_PASSWORD=test` — пароль для подключения к базе данных.
- `DB_PORT=27017` — порт для подключения к базе данных.
- `DB_NAME=six-cities` — имя базы данных MongoDB.
- `UPLOAD_DIRECTORY=upload` — директория для загружаемых файлов (аватары, превью,
  фотографии жилья).
- `JWT_SECRET=super-secret-jwt` — секрет для подписи JWT-токенов.
- `STATIC_DIRECTORY_PATH=static` — путь к директории со статическими ресурсами
  (изображения по умолчанию).

Файлы `.env` не должны попадать в систему контроля версий. В репозитории хранится
только `.env.example` с примерами значений.

## Сценарии

В `package.json` предопределено несколько сценариев.

### Запустить CLI

```bash
npm run cli -- <команда> [аргументы]
```

Запускает интерфейс командной строки для подготовки данных. Поддерживаемые команды:

- `--version` — выводит версию приложения (из `package.json`);
- `--help` — выводит список поддерживаемых команд;
- `--generate <n> <filepath> <url>` — генерирует `n` тестовых предложений и
  сохраняет их в TSV-файл по пути `filepath`, используя данные с адреса `url`;
- `--import <filepath> <login> <password> <host> <dbname>` — импортирует данные
  из TSV-файла в базу данных.

Запуск без аргументов выполняет команду `--help`.

### Запустить проект

```bash
npm start
```

Выполняет сборку проекта и запуск результирующего кода из директории `dist`.

### Запустить проект в режиме разработки

```bash
npm run start:dev
```

Запускает сервис через `nodemon` с автоматической перезагрузкой при изменении кода.

### Собрать проект

```bash
npm run build
```

Удаляет ранее скомпилированный проект и компилирует заново.

### Скомпилировать проект

```bash
npm run compile
```

Создаёт директорию `dist` и компилирует проект (`tsc`).

### Удалить скомпилированный проект

```bash
npm run clean
```

Удаляет директорию `dist`. Используется перед компиляцией.

### Проверить линтером

```bash
npm run lint
```

Запускает проверку проекта статическим анализатором кода **ESLint**. Проверяются
только файлы внутри директории `src`. Ошибки выводятся в терминал.

### Запустить ts-модуль без компиляции

```bash
npm run ts -- <путь к модулю с ts-кодом>
```

Пакет `tsx` позволяет выполнить TS-код в Node.js без предварительной компиляции.
Используется только на этапе разработки.

### Запустить json-сервер

```bash
npm run json-server
```

Запускает `json-server` с тестовыми данными из `./mocks/mock-server-data.json` на
порту `3000`. Используется командой `--generate` как источник данных.

## Структура проекта

### Директория `src`

Исходный код проекта: компоненты, модули, CLI, REST-сервис и так далее.

### Директория `specification`

Спецификация REST API в формате OpenAPI (`specification.yml`).

### Файл `.env.example`

Пример файла с переменными окружения, необходимыми для работы сервиса.

### Файл `docker-compose.yml`

Конфигурация для быстрого разворачивания базы данных MongoDB с помощью Docker.

### Файл `Readme.md`

Инструкции по работе с учебным репозиторием.

### Файл `Contributing.md`

Советы и инструкции по внесению изменений в учебный репозиторий.

### Остальное

Все остальные файлы в проекте являются служебными.
